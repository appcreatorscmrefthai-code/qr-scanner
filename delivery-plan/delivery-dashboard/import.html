นำเข้าแผนจัดส่ง

ปฏิทิน Dashboard วันนี้
  1. ใน Excel (หรือ Google Sheet) เลือกแถวแผนที่ต้องการ ให้ครบทุกคอลัมน์ A ถึง Y (Task Code ถึง Task Status) แล้วกด Ctrl+C จะรวมแถวหัวตารางมาด้วยหรือไม่ก็ได้
  2. คลิกในช่องด้านล่าง แล้วกด Ctrl+V ระบบจะตรวจข้อมูลและแสดงตัวอย่างให้ดูก่อน
  3. ตรวจตัวอย่างแล้วกด นำเข้า งานที่ Task Code ซ้ำกับในระบบจะถูกแทนที่ด้วยข้อมูลใหม่ (QR เดิมยังใช้ได้) งานที่ยังไม่มีจะถูกเพิ่ม
