3) สร้างไฟล์ Excel ตอนนี้ (ข้อมูลสด)

ดึงข้อมูลปัจจุบันจากระบบแล้วสร้างไฟล์ Excel ในเครื่องคุณทันที (ใช้ชีตและคอลัมน์เดียวกับไฟล์ Backup รายคืน) ไม่ต้องรอรอบ 22:00 น.

4) Backup เก็บไว้ที่ไหน

  • ทุกวัน 22:00 น. เครื่องของ Admin จะดึงข้อมูลและรูปทั้งหมดมาเก็บไว้ในเครื่อง Admin เอง
  • รูปแยกโฟลเดอร์ตาม Task Code เช่น D20261008-02 > ส่งจากคลังสินค้า > รูป หัวข้อมี ส่งจากคลังสินค้า, สถานการณ์บนถนน, ลงงานจุดที่ 1-3, ลงงานส่งกลับ
  • ข้อมูลทั้งหมด (Plan / Pickup / Road / Edit / Delay) อยู่ในไฟล์ Excel ที่ดาวน์โหลดได้จากหน้านี้ งานที่ถูกลบออกจากระบบแล้วยังคงอยู่ในไฟล์ Backup (ช่อง “สถานะใน Backup”)
  • ต้องการรูปต้นฉบับของงานเก่า ให้แจ้ง Admin ระบุ Task Code
