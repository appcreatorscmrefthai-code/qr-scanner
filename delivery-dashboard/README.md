# Delivery Plan Dashboard

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ปฏิทินรายเดือน คลิกวันเพื่อเปิด Dashboard ของวันนั้น |
| `dashboard.html` | Dashboard (ไม่ใส่ date = วันนี้อัตโนมัติ) คลิกรถเพื่อดูรายละเอียดและแก้ไขข้อมูล |

| `qr.html` | ฟอร์ม QR ประจำงาน เลือกชนิดก่อนพิมพ์: รายงานคนขับ (1 งานต่อหน้า) / รายงานคลังสินค้า (2 งานต่อหน้า) |

## ชีตใน Google Sheet
- `Plan` 24 คอลัมน์ (A-X) ตรงกับชีต Plan ใน Excel ช่องที่เป็น `-` ถือว่าว่าง
- `Pickup_Log` รูปส่งงาน
- `Road_Log` ทุกรายการจากฟอร์มผู้จัดส่ง (เช็คอิน / บนถนน / ถึงหน้างาน / ลงงานเสร็จ) พร้อมเวลา
- `Edit_Log` ประวัติการแก้ไข (ทะเบียนรถตอนเช็คอิน และการแก้จาก Popup) พร้อมชื่อผู้แก้ไข
- `Users` ผู้ใช้ Dashboard: Username, Password, สิทธิ์ (`edit` = ดูและแก้ไข, `view` = ดูอย่างเดียว), ชื่อที่แสดง, ใช้งาน

รัน `setup` ซ้ำได้ ถ้าหัวตารางของชีตเดิมไม่ตรงกับโครงใหม่และมีข้อมูลอยู่ ชีตเดิมจะถูกเปลี่ยนชื่อเป็น `<ชื่อ>_old_<วันเวลา>` แล้วสร้างชีตใหม่

## กติกาการแจ้งเตือน
- **Delay (กรอบแดง):** เลย Arrival Time ของจุดใดแล้วรถยังไม่กด "ถึงหน้างาน" จุดนั้น
- **Follow (กรอบเหลือง):** เลยตารางเวลาเกิน `CHECKIN_LATE_MIN` นาทีแล้วรถยังไม่เช็คอิน หรือรถออกแล้วเกิน `NO_ROAD_UPDATE_MIN` นาที ยังไม่ส่งสถานการณ์บนถนน (ตั้ง `FOLLOW_REPEAT: true` เพื่อเตือนซ้ำทุกครั้งที่เงียบเกินเวลา)

## ผู้ใช้และสิทธิ์
- Dashboard, ปฏิทิน และหน้า QR ต้องเข้าสู่ระบบ ส่วนฟอร์มของคนขับ (pickup / road) ไม่ต้อง
- เพิ่มผู้ใช้: เพิ่มแถวในชีต `Users` พิมพ์รหัสผ่านลงช่อง Password ได้เลย ระบบจะเปลี่ยนเป็นค่าเข้ารหัส (`sha256:...`) ให้เองเมื่อมีการเข้าสู่ระบบครั้งถัดไป
- เปลี่ยนรหัสผ่าน: พิมพ์รหัสใหม่ทับค่าเดิมในช่อง Password
- ปิดผู้ใช้: ใส่ `FALSE` ในช่องใช้งาน
- ผู้ใช้เริ่มต้นจาก `setup`: `admin` / `scm@1234` (edit) และ `viewer` / `view@1234` (view) ควรเปลี่ยนรหัสทันที

## งานไป-กลับ
ถ้าคอลัมน์รอบขนส่งมีคำว่า "กลับ" (เช่น `ไป-กลับ`) เส้นทางจะมีจุด ↩ กลับ SCM ต่อท้าย และงานจะจบเมื่อคนขับกด "รถกลับถึง SCM"

## ตั้งค่าใน Code.gs
- `SESSION_DAYS` เข้าสู่ระบบ 1 ครั้งใช้ได้กี่วัน
- `SYNC_KEY` รหัสสำหรับปุ่ม VBA ส่งแผนจาก Excel

เมื่อแก้ `Code.gs` ต้อง Deploy > Manage deployments > Edit > Version: New version ทุกครั้ง

## ค้นหาบน Dashboard
ค้นได้จาก Task Code, Client Name, ทะเบียนรถ และชื่อจุดส่ง 1-3 ใส่หลายค่าได้โดยคั่นด้วย `,` จะแสดงงานที่ตรงกับค่าใดค่าหนึ่ง

## ฟอร์ม QR
ข้อความ "วิธีใช้" และรายการเอกสารในตารางของรายงานคนขับ แก้ได้ที่ `QR_HELP_DRIVER`, `QR_HELP_LOADER`, `QR_DOCS` ใน `config.js`

## GPS + ETA
- ส่งตำแหน่งรถ: ใน Excel กดปุ่ม **ส่งตำแหน่ง GPS** แล้วเลือกไฟล์ "ข้อมูลรถปัจจุบัน" ที่ Export จาก DTCUltimate (ทะเบียนจับคู่กับ Plan โดยไม่สนช่องว่าง/ขีด)
- พิกัดจุดส่ง: หน้า `eta.html` (ตั้งค่า ETA / GPS) ใส่ชื่อจุด + พิกัด หรือวางลิงก์ Google Maps แบบเต็ม ระบบอ่านพิกัดจากช่องแผนที่ใน Plan ให้ด้วยถ้ามี
- ETA = ระยะเส้นตรง × ตัวคูณทางอ้อม ÷ ความเร็ว (ความเร็วเฉลี่ยล่าสุดของรถคันนั้น หรือค่าเริ่มต้น) + เวลาลงของต่อจุด เทียบกับเวลานัด: ทันเวลา / เสี่ยงสาย / คาดว่าจะสาย (ปรับเกณฑ์ได้ในหน้า eta.html)
- งานข้ามวัน: เวลานัดที่น้อยกว่าจุดก่อนหน้าถือว่าเป็นวันถัดไป
- ถ้าตั้งพิกัดต้นทาง (SCM) แล้ว GPS จะบันทึกเช็คอิน/ออก/ถึงจุด/ลงงาน/กลับต้นทางให้เอง (หมายเหตุขึ้นต้น "GPS อัตโนมัติ") ปิดได้ที่ค่า auto_events = 0

## ลิงก์ QR ไม่ใช้รหัสลับ + ฟอร์ม 2 แบบ + ที่มาของสถานะ (รุ่น s7)
- QR/ลิงก์เป็นแบบ `?task=<Task Code>` เท่านั้น ลบงานแล้วสร้างใหม่ด้วย Task Code เดิม ลิงก์ที่ส่งไปแล้วใช้ต่อได้ (QR รุ่นเก่าที่มี `&k=` ยังใช้ได้)
- ตัวกันแทนรหัสลับ: งานที่ยกเลิกเปิดไม่ได้, เปิด/ส่งได้เฉพาะงานที่วันที่อยู่ในช่วง วันนี้-3 ถึง วันนี้+1 (เวลาไทย), รูปอัปโหลดได้เฉพาะโฟลเดอร์ `<Task Code>/p/`, จำกัดจำนวนรายการต่องาน (road 300 / pickup 100)
- ฟอร์มคนขับเลือกตามช่อง "ชื่อบริษัทขนส่ง": มีคำว่า "ปทุมทรานสปอร์ต" (ไม่สนช่องว่าง) -> `road-gps.html` (สถานะเข้า SCM / ออก / ถึงหน้างาน มาจาก GPS คนขับส่งเฉพาะสถานการณ์เมื่อออกไปแล้ว 1 ชม. และรูปลงงานแบบไม่บังคับ) บริษัทอื่น -> `road.html` ฟอร์มเดิม  มีลิงก์ "ใช้ฟอร์มปกติ" กรณี GPS ไม่ทำงาน
- ทุกรายการใน Log มีคอลัมน์ `source` = `คน` หรือ `GPS` แสดงเป็นป้ายบน Dashboard (ใต้รถ, รายการจุดส่ง, Popup Log) และคอลัมน์ "ที่มา (คน/GPS)" ท้ายชีต Pickup_Log / Road_Log ใน Excel

## เติมพิกัดจุดส่งอัตโนมัติจากลิงก์แผนที่ (รุ่น s8)
- หลังกด "ส่งงานใหม่ขึ้นระบบ" / "ส่งการแก้ไขขึ้นระบบ" macro จะตามลิงก์ย่อ (maps.app.goo.gl) ในช่อง Map1-3 ไปอ่านพิกัดหมุดจริง (!3d/!4d) แล้วเพิ่มเข้าตารางจุดส่ง (`places`) เฉพาะชื่อที่ยังไม่มี ไม่เขียนทับค่าที่ตั้งเอง
- ปุ่ม "เติมพิกัดจุดส่งจากลิงก์" ทำเฉพาะส่วนนี้ (ใช้กับงานที่ส่งไปก่อนหน้านี้ ครอบคลุมงานวันที่ย้อนหลัง 7 วันขึ้นไป) ครั้งละไม่เกิน 60 ลิงก์
- ลิงก์เต็มที่มีพิกัดระบบอ่านเองได้อยู่แล้ว ลิงก์ที่อ่านไม่ได้จะแจ้งชื่อจุด ให้ใส่เองที่หน้า eta.html


## รุ่น s10 (ตุลาคม 2569) : สิ่งที่เพิ่ม

1. **ฟอร์มคนขับ (road.html)** : เพิ่มปุ่ม "รถออกจาก SCM" (เช็คเอาท์) และปุ่ม "รถกลับถึง SCM" แนบรูปที่ SCM ได้
2. **ฟอร์ม GPS (road-gps.html)** : GPS บันทึก เข้า/ออก/ถึง/ลงงาน/กลับ เอง คนขับแนบรูปลงงานแต่ละจุดและรูปคืน SCM ได้ 24 ชม. หลังเหตุการณ์ แล้วปุ่มปิด
3. **คลังสินค้า (pickup.html)** : ไม่บันทึกเวลารถออกแล้ว เก็บเฉพาะรูป อัปโหลดเพิ่มได้ 24 ชม. นับจากครั้งล่าสุด Dashboard แสดง "📦 มีรูปจากคลังสินค้าแล้ว"
4. **Dashboard** : ป้าย ETA (ทันเวลา / เสี่ยงสาย / สาย) ด้านขวาทั้ง GPS (📡) และคนกรอก (👤)
5. **gps.html** : แผนที่ (Leaflet + OpenStreetMap) หมุด SCM/จุดส่ง/รถ ตามสถานะ เส้นทางที่วิ่งมา กล่องรายละเอียดมุมซ้ายล่าง KPI ของวัน Delay Trend รายวัน/รายเดือน รีเฟรชทุก 60 วินาที (จุดที่ไม่มีพิกัดจะไม่แสดงหมุด)
6. **backup.html** : ดาวน์โหลดไฟล์ Excel Backup ผ่านเว็บ และบอต Backup 22:00 บนเครื่อง Admin (โฟลเดอร์ backup-bot)
8. **สร้างงานจากหน้าเว็บ (s11)** : ปุ่ม "+ สร้างงาน" บน Dashboard (เฉพาะสิทธิ์ edit / admin) Task Code รันต่อจากเลขล่าสุดของวันนั้น เช่น D20261008-04 → D20261008-05 กรอกเหมือน Popup แก้ไข
7. **Excel macro** : Plan = ส่งอย่างเดียว, Plan_Backup = สำรองจากเว็บและเป็นต้นทางของการแก้ไข, เติมพิกัดจุดส่งอัตโนมัติหลังส่ง, Delay Trend ลง Excel
